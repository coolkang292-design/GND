# GND 예시 화면 · 연출 인증사진 작업지시서 (GPT 이미지 생성용, 6장)

> **무엇에 쓰나.** 크루가 0명인 새 회원이 "챌린지는 이렇게 흘러가요" 예시 화면에서 보는
> **가짜 회원의 인증사진**이다. 실제 회원 사진은 한 장도 쓰지 않는다.
> 화면 맨 위에는 항상 "예시 화면이에요 · 실제 회원이 아니에요" 띠가 붙는다.
>
> 작성 2026-11-26. 앱 적용은 에이전트가 한다(§6). **이 문서는 배포 승인이 아니다.**

---

## 0. 한눈에 보는 규격

```
비율        가로 4:3 (예: 1600 × 1200)
            ↳ 4:3이 안 되면 가로 3:2(1536 × 1024)도 괜찮다. 양옆을 잘라 4:3으로 맞춘다
형식        PNG 또는 JPG (원본 그대로. 크기 줄이기·변환은 에이전트가 한다)
느낌        스마트폰으로 찍은 자연스러운 인증사진. 광고 사진처럼 반짝이지 않게
장수        6장 (아래 §3 표)
저장        저장소 루트의 `예시 인증사진/` 폴더 (깃허브에 안 올라가는 폴더)
파일명      §3 표의 파일명 그대로 (예: 1-jieun-run.png)
```

### 왜 이 규격인가

- **4:3** — 앱 피드의 사진 칸이 가로 4:3이다. 비율이 다르면 앱이 사진을 꽉 채우느라
  위아래나 양옆을 잘라 낸다(`object-cover`).
- **원본으로 받는다** — 앱에 넣을 때 에이전트가 가벼운 형식(webp)으로 바꾸고 크기를 줄인다.
  미리 줄여 오면 화질만 두 번 깎인다.

## 1. 사진 위에 앱이 덮는 자리 — 주인공은 가운데에

앱은 사진 위에 세 가지를 겹쳐 그린다. **이 자리에 중요한 것을 두면 가려진다.**

```
┌─────────────────────────────────┐
│ (●) 지은  · 3시간 전 운동 완료   2/2 │ ← 위쪽 약 20%: 프로필 줄 + 장 수 표시
│                                 │
│         ★ 주인공은 여기 ★         │ ← 가운데 약 55%
│                                 │
│ ▓▓▓ 2026.11.26 WED  07:12 · 32분 ▓▓│ ← 아래쪽 약 25%: 검은 그라데이션 + 날짜
└─────────────────────────────────┘
```

- 위쪽과 아래쪽은 **바닥, 하늘, 벽처럼 비어도 되는 배경**이면 좋다
- 아래쪽은 검게 어두워지므로, 거기에 운동화나 덤벨을 두면 안 보인다

## 2. 절대 넣지 말 것 — 이유도 같이

| 넣지 말 것 | 왜 |
|---|---|
| **글자·숫자** (간판, 화면, 시계, 원판 무게 표시 포함) | AI는 글자를 이상하게 그린다. 사진 속 숫자(예: 시계의 45분)가 카드 기록(32분)과 다르면 어색하다 |
| **브랜드 로고** (운동화, 옷, 기구, 물병) | 상표 문제가 생길 수 있다 |
| **알아볼 수 있는 얼굴** | AI 얼굴이 우연히 실제 사람과 닮을 수 있다. 가짜 얼굴은 "진짜 회원인 척"으로 보인다 |
| **다른 사람** (배경 속 사람 포함) | 위와 같은 이유. 빈 헬스장이나 흐릿한 배경으로 |
| **과한 보정** (HDR, 영화 같은 조명, 지나친 선명함) | 인증사진이 아니라 광고처럼 보인다 |
| **선정적이거나 몸매를 강조하는 구도** | 운동 기록 앱의 예시로 맞지 않는다 |

## 3. 6장 목록 — 예시 회원의 이야기에 맞춘다

예시 화면은 "한 챌린지(3주 동안 주 3회 운동)에 참가한 사람들의 하루"를 보여준다.
**사진의 시간대와 장소가 카드에 적힐 운동 기록과 맞아야 한다.**

| # | 파일명 | 예시 회원 | 운동 · 시간대 | 사진 내용 |
|---|---|---|---|---|
| 1 | `1-jieun-run.png` | 지은 | 러닝 · 아침 7시 | 아침 햇살 비치는 강변 산책로, 러닝화 신은 발끝 |
| 2 | `2-minsu-squat.png` | 민수 | 하체 웨이트 · 저녁 8시 | 원판 꽂힌 스쿼트 랙, 헬스장 조명 |
| 3 | `3-minsu-dumbbell.png` | 민수 | 같은 운동의 두 번째 장 | 고무 바닥에 놓인 덤벨 한 쌍과 운동 장갑 |
| 4 | `4-sora-stretch.png` | 소라 | 스트레칭 · 밤 10시 | 집 거실 요가 매트, 물병, 폼롤러 (위에서 내려다봄) |
| 5 | `5-hyunwoo-bike.png` | 현우 | 실내 자전거 · 저녁 7시 | 실내 자전거 손잡이에 걸린 땀 수건 |
| 6 | `6-yujin-mirror.png` | 유진 | 첫 운동 · 오후 3시 | 헬스장 거울 셀카, 얼굴은 폰으로 가림 |

- 2번과 3번은 **한 게시물에 사진 두 장**이다. 옆으로 넘기는 모습을 보여주려고 넣었다.
  같은 헬스장, 같은 조명으로 보여야 한다.
- 6번만 사람이 나온다. 얼굴은 반드시 스마트폰으로 가린다.

## 4. 작업 순서 — 이 순서를 지킬 것

```
① 공통 문장(§5-0) + 1번 프롬프트로 1장 생성        ← 분위기 기준 사진
② 마음에 들 때까지 1번을 다시 생성해 확정
③ 2~6번은 확정한 1번을 첨부하고
   "이 사진과 같은 색감·화질·카메라 느낌으로" 를 붙여 생성   ← 6장이 한 앱 사진처럼 보이게
④ 3번은 2번을 첨부해 "같은 헬스장, 같은 조명" 으로 생성
⑤ §7 검수표로 한 장씩 확인 → 걸리면 그 장만 다시 생성
⑥ `예시 인증사진/` 폴더에 파일명대로 저장 → 에이전트에게 "사진 넣었어" 라고 알림
```

**왜 기준 사진부터인가.** 6장을 따로 만들면 한 장은 필름 사진 같고 한 장은 광고 사진 같은
식으로 색감이 제각각이 된다. 한 앱의 피드처럼 보이려면 기준 사진을 첨부해 맞춰야 한다.
배지 30장을 만들 때도 이 방법이 통했다(`docs/badge-asset-prompts.md` §2).

## 5. 프롬프트 — 그대로 복사해서 붙여 넣는다

### 5-0. 공통 문장 (모든 장 맨 앞에 붙인다)

```
스마트폰 기본 카메라로 찍은 자연스러운 운동 인증사진. 가로 4:3 비율.
사람이 직접 찍은 듯한 살짝 비스듬한 구도, 과한 보정·HDR·영화 같은 조명 없음.
한국의 일상적인 장소 분위기.
사진 안에 글자·숫자·간판·로고·브랜드 표시가 전혀 없을 것. 화면이나 시계는 꺼져 있거나 보이지 않을 것.
알아볼 수 있는 사람 얼굴 없음. 배경에 다른 사람 없음.
주인공은 화면 가운데에 두고, 사진의 위쪽 20%와 아래쪽 25%는 바닥·하늘·벽처럼 비어도 되는 배경으로.
```

```
러닝을 막 끝낸 사람이 자기 발을 내려다보며 찍은 사진: 산책로 위에 선 러닝화 두 짝과 발목까지만 보인다.

```

## 6. 사진을 받은 뒤 — 에이전트가 할 일

1. `예시 인증사진/`의 6장을 **한 장씩 눈으로** 본다(§7 검수표). 걸린 장은 이유와 함께 다시 요청한다
2. 4:3이 아니면 가운데를 기준으로 4:3으로 자른다
3. 가로 1200px 정도 webp로 바꿔 `public/example-tour/`에 넣는다(장당 200KB 이하 목표).
   파일명은 영문 그대로 쓴다(`jieun-run.webp` 등) — 주소에 한글이 들어가면 깨질 수 있다
4. 예시 데이터 파일에서 각 가짜 게시물에 연결한다
5. 연습용 앱(`pnpm dev`)에서 예시 화면을 열어 사진 6장이 다 뜨는지, 프로필 줄과 날짜 띠에
   주인공이 가리지 않는지, 2번과 3번이 옆으로 넘어가는지 직접 확인한다

## 7. 검수표 — 한 장이라도 걸리면 그 장만 다시 만든다

- [ ] 가로 4:3(또는 3:2)인가
- [ ] **글자·숫자·로고가 하나도 없는가** (원판, 시계, 화면, 신발, 옷, 물병까지 확대해서 본다)
- [ ] 알아볼 수 있는 얼굴이 없는가 (6번: 폰이 얼굴을 다 가렸는가)
- [ ] 배경이나 거울에 다른 사람이 없는가
- [ ] 손가락, 발, 기구 모양이 이상하지 않은가 (손가락 개수, 신발 두 짝, 바벨 양끝)
- [ ] 주인공이 가운데에 있고 위 20%·아래 25%에 중요한 것이 없는가
- [ ] 시간대가 표와 맞는가 (아침 햇살 / 저녁 조명 / 밤 스탠드)
- [ ] 6장이 한 앱의 사진처럼 색감이 비슷한가
- [ ] 광고 사진처럼 과하게 반짝이지 않는가
