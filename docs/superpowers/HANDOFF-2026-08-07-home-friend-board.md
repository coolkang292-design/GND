### 1.1 사용자가 보는 변화

**홈**
- 진행 중 운동 카드 **바로 아래**에 `👥 친구 N명` 카드가 새로 생겼다
- 친구 한 명당: 현재 레벨 캐릭터 아바타 · 닉네임 · `Lv.N` 골드 알약 · 오늘 상태 알약 ·
  콕 버튼 / `운동 N회` `시간 N` `연속 N일` 3칸 / 배지 썸네일 + `배지 N개`
- 기본 **3명**, 4명 이상이면 `전체 보기 ›`로 그 자리에서 펼친다
- 친구를 누르면 성과 시트(누적 · 스트릭 · 이번 주 + 보유 배지)
- **홈에서 사라진 것**: `🏆 챌린지 참가자 성과` 카드 · 크루 카드의 멤버 칩과 `👉 콕`

**챌린지 탭 (active일 때)**
- `🔒 공정성을 위해…` 배너 **바로 아래**에 `🏆 챌린지 참가자 성과` 카드가 생겼다
  (5일 연속 → 2시간 열람권. 기능은 홈에 있던 그대로)

**크루 카드**
- 크루명 · 초대 코드 · 초대 링크 복사만 남았다. 문구가 **무엇에 대한 초대인지** 말한다

## 2. 사용자 화면 확인에서 잡힌 것 (전부 반영·배포됨)

옮겨 적는 이유는 **같은 실수를 되돌리지 말라는 뜻**이다. 각 항목은 테스트로 고정돼 있다.

1. **콕이 "상대가 오늘 운동 안 했을 때만" 떴다 — 실버그.**
   옛 크루 카드의 화면 규칙을 그대로 옮긴 것인데 **서버 `poke_user`에는 그런 조건이 없다**
   (0028이 건 조건은 *내가* 오늘 했는가 하나뿐). 그 탓에 **오늘 운동을 마친 친구는 영영 못 찔렀다.**
   → 상대 상태와 무관하게 모두 찌를 수 있다. 24시간 쿨다운은 서버 규칙 그대로. **DB 변경 0**
2. **①을 고치자 정렬의 근거가 사라졌다.** "오늘 안 한 친구 먼저"의 유일한 이유가
   *찌를 수 있는 사람이 접힌 3행 안에 있어야 한다*였다 → **최근 운동순 → 닉네임**으로 바꿨다
3. **아바타가 프로필 이모지였다** → 현재 레벨 캐릭터 이미지(`getLevelProgress().characterPath`)
4. **배지가 `🏅6`이었다** → 실제 PNG 썸네일 3개 + `+N`. 키는 이미 받아 오던 것이라 **조회 0**
5. **지표가 `28회 · 21분 · 🏅6 · 🔥5`였다** — 각 숫자가 뭔지 알 수 없다 →
   `운동`/`시간`/`연속` 라벨을 붙이고 **3칸 고정 그리드**로(친구끼리 세로가 맞는다)
6. **초대 문구가 무엇에 대한 초대인지 안 말했다** → 앱 초대임을 명시하고 챌린지 초대와 구별

## 3. 코드 지도

```
src/lib/domain/friend-board.ts        263줄  순수 계층 — 집계·정렬·상태·펼치기·표기
src/lib/friends.ts                    155줄  조회 계층 — RPC 2 + 질의 1 + 배지 N
src/components/home/friend-board-card.tsx      418줄  홈 카드 (셸 + FriendBoardBody)
src/components/challenge/participant-performance-card.tsx  220줄  홈에서 옮겨 온 카드
src/components/crew-card.tsx          222줄  콕·멤버 칩이 빠진 뒤의 크루 카드
```

**계층 규약** — 이걸 지켜야 테스트가 유지된다.
- `domain/friend-board.ts`는 **I/O가 없다.** 조회는 `lib/friends.ts`만 한다
- `friend-board-card.tsx`는 **셸(`FriendBoardCard`)과 본문(`FriendBoardBody`)이 분리**돼 있다.
  본문은 props만 받는 순수 표시 컴포넌트라 테스트가 붙는다 (`MemberProfileBody`와 같은 이유)
- `MemberProfileSheet`는 `domain/friend-board` 타입을 **import하지 않는다.** 성과 블록은
  `MemberPerformance`라는 **구조적 타입**으로 받는다 — 크루 시트가 홈 모듈에 묶이면 안 된다

**조회 흐름** (모두 기존 자산, 새 DB 작업 0)

| 무엇 | 어디서 | 비고 |
|---|---|---|
| 친구 명단·닉네임·아바타·`total_xp` | `get_my_crew()` RPC | 이미 있던 정의자 함수 |
| 누적 횟수·시간·오늘여부·스트릭·주간 | `workout_sessions` 질의 1개 | RLS가 크루 공개분만 준다 |

## 5. 함정 (반드시 읽어라)

### 5.1 콕을 두 곳에 두면 버튼이 거짓말을 한다
`poked` Set이 컴포넌트마다 따로다. 한쪽에서 찔러 `✅ 찌름`으로 잠가도 **다른 쪽 버튼은 열린 채**
남고, 두 번째 누름은 서버 `poke_cooldown` 에러 토스트로만 드러난다. 두 곳에 두려면
상태를 `HomeClient`로 끌어올려 같은 값을 내려야 한다. `crew-card.test.tsx`가 부정 단언으로 막는다.

### 5.2 상대의 오늘 운동 여부로 콕을 숨기지 마라
서버 `poke_user`에 그런 조건이 **없다.** 숨기면 오늘 운동을 마친 친구를 영영 못 찌른다(§2-①).

### 5.3 내가 오늘 운동했는지는 목록 질의로 판정하면 안 된다
목록 질의는 `visibility='group'`으로 좁혀 있는데 서버 `poke_requires_workout`(0028)은
**내 세션 전부**를 본다. 좁힌 값으로 판정하면 *서버는 허용하는데 버튼만 흐릿한* 막다른 길이 생긴다.
→ 홈의 `completedAts`(무필터)를 `workedOutToday()`에 넣는다.

### 5.4 레벨은 `total_xp`로 계산한다. 캐시 컬럼을 쓰지 마라
`user_progress.current_level`을 쓰면 같은 사람이 화면마다 다른 레벨로 보인다.
2026-08-07에 `crew-list.tsx`도 같은 규칙으로 통일했다.
**실제로 갈렸던 증거**: 테스트 픽스처가 `totalXp: 640` + `currentLevel: 3`인데 진짜 값은 **Lv.4**다.

### 5.5 배지 키는 카탈로그와 교집합만 그린다
`get_crew_member_profile`은 `user_badges` 행을 그대로 준다 — 카탈로그에서 내린 배지 키가
섞이면 `/badges/<key>.png`가 **깨진 이미지**로 뜬다. 개수(`earnedBadgeCount`)는 원래 걸렀지만
키는 안 걸러져 있었다.

### 5.6 `badgeCount: number | null`의 `null`을 `0`으로 바꾸지 마라
`null` = 아직 안 왔거나 조회 실패, `0` = 정말 배지가 없음. 화면도 둘을 구별한다
(`배지 불러오는 중…` vs `아직 배지가 없어요`). 2026-08-02에 `routines`를 `[]`로 초기화했다가
조회 실패를 0개로 착각해 실버그가 났다 — 그 반복을 막으려고 타입으로 갈라 뒀다.

### 5.7 챌린지 성과 카드는 볼 챌린지를 스스로 고르지 않는다
옛 홈 버전은 `getMyChallenges` → `pickPrimaryRow`로 대표를 직접 골랐다. 챌린지 탭에는
**사용자가 고른 챌린지**(`selectedId`)가 따로 있어서, 되돌리면 탭과 카드가 다른 챌린지를 그린다
(0044에서 같은 종류의 사고가 있었다). 전환 시 초기화는 **부모의 `key={challenge.id}`**로 한다 —
카드 내부에서 비우면 effect 본문 setState가 되어 `react-hooks/set-state-in-effect`가 막는다.

### 5.8 지표 3칸 그리드에서 값이 0이라고 칩을 빼지 마라
그 행만 칸이 밀려 친구끼리 세로가 안 맞는다. `연속 0일`도 그린다.

### 5.9 정렬 tiebreak에서 `null`을 `-Infinity`로 접지 마라
기록 없는 사람끼리 비교하면 `-Infinity - -Infinity = NaN`이 되고, **비교 함수가 NaN을 돌려주면
정렬 결과가 정의되지 않는다** — 닉네임 갈래로 넘어가지도 못한다. 첫 테스트 실행이 이걸 잡았다.

### 5.10 `ActiveWorkoutCards`의 `sessions` prop
값을 넘기면 그리기만 하고, 안 넘기면 스스로 조회+60초 폴링한다. **피드 페이지는 안 넘긴다** —
prop을 필수로 바꾸면 피드가 깨진다. 홈은 넘겨서 같은 질의가 두 번 나가는 것을 막는다.

### 5.11 세션 질의의 행 상한
`limit(FRIEND_SESSION_ROW_LIMIT=2000)`은 자르려는 게 아니라 **잘렸는지 알려고** 건다.
상한에 닿으면 `truncated: true`로 화면이 "일부만 반영된 수치예요"를 띄운다.
2026-08-07 운영 실측 완료 세션 총계는 **79건**이라 당장 위험은 없다.

### 5.12 Bash 도구에서 PowerShell here-string(`@'…'@`)을 쓰지 마라
커밋 메시지 제목에 `@`가 그대로 박혔다(이번에 한 번 밟았다). heredoc(`<<'EOF'`)을 써라.

## 9. 작업 트리 주의

`git status`에 **다른 세션이 만든 미추적 파일**이 남아 있다. 이번 작업과 **무관하므로 커밋하지 마라.**

```
.superpowers/            docs/design-sources/     public/avatar-mock/
7단계 캐릭터/            배지이미지/              이미지 꾸미기/
scripts/compose-avatar-items-temp.py
scripts/prepare-avatar-base-temp.py
scripts/validate-avatar-mock-assets.mjs
```

커밋할 때는 `git add <파일>`로 **경로를 하나씩 지정**해라. `git add -A`를 쓰면 위가 전부 섞인다.
