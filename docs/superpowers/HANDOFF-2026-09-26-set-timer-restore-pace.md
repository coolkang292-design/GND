## 1. 왜

사용자 신고: 트레드밀을 `▶ 시작`으로 재는 중 아이폰에 **"입력 취소"** 팝업이 자꾸 뜬다 +
화면을 꺼도 시계가 도는가.

- "입력 취소"는 iOS **흔들어서 실행 취소**다. 웹앱이 막을 API가 없다. 운동 중 오버레이에는
  입력칸이 없고(± 버튼뿐), 그 전에 타이핑한 것(종목 검색·목록 카드의 숫자칸)이 되돌리기
  기록에 남아서 뜬다(추정). **해결은 기기 설정: 손쉬운 사용 → 터치 → 흔들어서 실행 취소 끄기.**
  이번 코드는 팝업을 없애지 않는다.
- 화면을 꺼도 경과 시간은 맞다(시작 시각 차이로 계산). 그런데 **시작 시각이 React 상태에만**
  있어서, 아이폰이 페이지를 버렸다 다시 열면 잰 시간이 통째로 사라졌다 ← 이번에 고친 것.
