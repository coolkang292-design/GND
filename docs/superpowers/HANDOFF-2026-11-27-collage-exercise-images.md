# 콜라주 운동 사진 두 장

2026-11-27에 사용자가 제공한 `블루 머슬 피트니스 콜라주.png`의 아래 두 컷을 적용했다. 원본 1312×1199에서 각 640×640 구역을 잘라 320×320 WebP로 줄였다.

| GND 운동 | 원본에서 자른 위치 (왼쪽, 위) | 운동 ID |
|---|---|---|
| 도어웨이 가슴 스트레칭 | (8, 559) | `ac897fe5-30df-466b-a190-e0a660a545c3` |
| 덤벨 런지 | (664, 559) | `63c9cf92-80bd-4d62-9c10-4b442bd44689` |

- 사진 파일과 연결표를 추가하고, 연결표를 다시 만드는 스크립트에도 두 항목을 등록했다.
- `http://localhost:3948/image-local-qa`의 실제 운동 선택 화면과 기록 카드를 크롬 폭 390px에서 확인했다. 검색 → 선택 → 2개 추가가 정상이며 두 화면 모두 사진이 48px로 표시됐다. 문틀과 양손, 덤벨과 두 발이 보였다. 사진 연결 검사 22개 통과.
- 실제 휴대폰과 로그인한 기록 저장은 미검증이다. 운영 데이터 쓰기와 운영 배포는 실행하지 않았다.
- 다음 할 일은 깃허브에 이 변경을 올릴지 확인하는 것이다. 흉추 익스텐션과 월 슬라이드는 사진에 나온 자세가 GND 종목과 일치하는지 확인한 뒤 다룬다.
