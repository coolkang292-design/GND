# GND 공식 추천 프로그램 설계 인수인계

## 현재 상태

코드는 아직 바꾸지 않았다. 사용자와 제품 결정을 마쳤고 설계 1개와 실행 계획 3개를
작성했다.

- 설계: `specs/2026-08-12-official-workout-programs-design.md`
- 1단계: `plans/2026-08-12-official-program-scheduling.md`
- 2단계: `plans/2026-08-12-program-guided-workout.md`
- 3단계: `plans/2026-08-12-exercise-guides-and-source-links.md`

## 확정된 핵심

- GND 공식 프로그램만 제공한다. 개인 `workout_routines`와 분리한다.
- 첫 프로그램은 `시선이 머무는 어깨` / `상체의 틀을 넓히는 6주`다.
- 주 3회 고정, 6주 18회, 시작 날짜와 요일별 시간을 사용자가 고른다.
- 충돌·결석은 기존 계획을 자동 삭제하지 않고 미리보기와 사용자 확인을 거친다.
- 최근 성공 무게 자동 입력, 종목별 반복 범위·휴식, 첫·마지막 세트 피드백을 쓴다.
- 운동 지침은 GND 안내가 본체이고 네이버 원문은 검수된 선택 링크다.

## 실행 순서와 게이트

1. 1단계 일정 등록을 먼저 구현한다.
2. 0066은 사용자가 SQL Editor에서 직접 Run해야 한다.
3. 개발 서버에서 18개 계획·충돌·재배치·일반 계획 회귀를 직접 조작한다.
4. 2단계의 0067도 사용자 SQL 적용 뒤 실 DB 검사를 실행한다.
5. 3단계는 DB 없이 구현하되 외부 링크를 추측해 추가하지 않는다.
6. 각 단계마다 lint·typecheck·전체 test·build 후 사용자 승인 전에는 배포하지 않는다.
