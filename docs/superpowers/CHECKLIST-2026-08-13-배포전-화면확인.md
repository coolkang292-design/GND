## 5. 달력

| # | 조작 | 기대 |
|---|---|---|
| 5.1 | 오늘 계획 열기 | 버튼이 **`운동 시작하기`** — `준비하기` 단계가 없다 |
| 5.2 | 오늘 인터벌 계획 | **`🔥 전신 인터벌 시작하기`** → 누르면 바로 전체화면 |
| 5.3 | 근력 계획 카드 | `0kg 0회`가 아니라 **`8–10회 목표`** + `무게는 시작할 때 최근 기록으로 채워져요` |
| 5.4 | 인터벌 계획 카드 | 종목마다 **`2회`** (입문 1주차 4분 기준) |
| 5.5 | 프로그램 계획 카드 | 삭제 버튼이 **`이 회차만 삭제`** 로 바뀌었고 그 아래 **`프로그램 그만두기`** |
| 5.6 | `프로그램 그만두기` | 남은 회차 수를 묻고, 확인하면 달력에서 **한 번에 사라진다** |
| 5.7 | 그만둔 뒤 | 같은 프로그램을 **다시 등록**할 수 있다 |
| 5.8 | 일반 계획 | 버튼이 `삭제` 하나뿐 (그만두기 없음) |
| 5.9 | 지난 인터벌 기록 → 📋 복사 | **복사된다** (예전엔 `복사할 종목이 없어요`로 막혔다) |
| 5.10 | 이미 운동이 있는 날 | 프로그램이 그 날짜를 **건너뛰고** 가까운 빈 날로 배치 (의도된 동작 · 사용자 확정) |

## 6. 인터벌 실행 — 가장 중요

| # | 조작 | 기대 |
|---|---|---|
| 6.1 | 인터벌 시작 | **전체화면 하나만.** 뒤에 ± 버튼·`현재 세트`가 안 보인다 |
| 6.2 | 화면 구성 | 지금 종목(크게) · `다음: ○○` · 응원 문구 · 종목 4칩 · 진행률 막대 |
| 6.3 | 카운트다운 숫자 | **없다** (숫자는 음악이 센다) |
| 6.4 | **소리와 화면** | 음악이 "3·2·1" 하고 종목을 부를 때 화면도 같이 바뀐다 |
| 6.5 | 8분으로 후반부(4분 이후) | 여전히 맞는다 (음원을 다시 이어 붙인 이유) |
| 6.6 | 20초 뒤 | 자동으로 다음 종목 · 10초 휴식 |
| 6.7 | 응원 문구 | 운동 중엔 미는 말, 휴식엔 회복하는 말. **깜빡이지 않는다** |
| 6.8 | 마지막 라운드 | `마지막 라운드! 끝까지` |
| 6.9 | 진행률 막대 | 라운드가 끝날 때마다 찬다 (막대가 **보이는지** 확인) |
| 6.10 | 일시정지 → 이어서 | 음악과 함께 멈췄다 재개 |
| 6.11 | 4분 끝까지 | **자동 종료 + 자동 기록** |

> ⚠️ 6.4가 아직 어긋나면 **몇 초 차이인지**만 알려주면 상수 하나로 맞춘다
> (`INTERVAL_PREP_SECONDS`, 현재 13초).

## 7. 인터벌 진입 경로 4가지

| # | 경로 | 기대 |
|---|---|---|
| 7.1 | 운동 추가 → 직접 고르기 → 상황별 → **`전신 인터벌 할래요`** | `전신 인터벌 고르러 가기` → 누르면 **바로 종목 고르기** |
| 7.2 | 지난 운동 불러오기 | 인터벌 줄에 **`🔥 인터벌 4분` 배지**, 오른쪽 문구가 `인터벌 시작` |
| 7.3 | 그 줄을 누르면 | 음원·코스까지 그때 것으로 되살아난다 |
| 7.4 | 인터벌을 **내 루틴으로 저장** → 불러오기 | 인터벌로 되살아난다 (일반 운동 4종목이 아니라) |

## 확인 뒤 배포 순서

1. 위 항목 확인 (이상 있으면 여기서 멈추고 고친다)
2. `pnpm lint && pnpm typecheck && pnpm test && pnpm build`
3. `main` 반영
4. **사용자 배포 승인**
5. `git archive HEAD`로 푼 `.git` 없는 폴더에서 `vercel --prod`
6. 프로덕션에서 **파일을 직접 받아** 새 코드가 들어갔는지 확인
7. 릴리스 노트 항목 추가 + **DRY RUN까지만** (발송은 별도 지시)

## 아직 못 한 것 (배포를 막지는 않는다)

- **네이버 지식백과 링크** — 화면 자리는 만들었으나 URL이 하나도 없다.
  이 세션에 웹 접근이 없어 열어 확인할 수 없었다. 규칙상 추측해 넣지 않는다
- **인터벌 회차 편집** (설계 §3.5) — 등록 전 종목 교체. 9조합이 전문가 검수를
  거치지 않았다는 점의 완화책이었다
