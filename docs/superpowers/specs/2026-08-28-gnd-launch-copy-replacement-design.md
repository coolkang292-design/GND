# GND 시작 이미지 문구 교체 설계

날짜: 2026-08-28

## 목표

현재 GND 시작 이미지의 장면과 브랜드 인상은 유지하면서 하단 문구만 아래 카피로
교체한다.

```text
의지가 꺾인 날에도
계속한 사람이, 결국 이긴다
```

## 승인된 시각 방향

- 사용자가 비교 시안에서 **A안 · 2줄 균형형**을 선택했다.
- 첫 줄은 흰색, 둘째 줄은 골드로 표현한다.
- 기존의 굵고 앞으로 기울어진 운동 포스터형 글자 인상을 유지한다.
- 상단 `GND`, 남녀 선수, 배틀로프, 비·물방울, 수증기, 젖은 바닥,
  블랙/골드 조명과 세로 구도는 바꾸지 않는다.
- 문구 이외의 새로운 글자·로고·장식은 추가하지 않는다.

## 구현 방식

기존 최종 이미지 `public/splash/gnd-launch-motivation-v4.png`를 편집 대상으로 사용한다.
ImageGen으로 하단 기존 문구 영역만 교체하고 나머지 픽셀 구성은 최대한 보존한다.

결과는 기존 파일을 덮어쓰지 않고
`public/splash/gnd-launch-motivation-v5.png`로 버전 관리한다. 이는 이전 이미지 캐시가
남아 새 문구 대신 과거 문구가 보이는 문제를 피하기 위함이다.

ImageGen이 한글을 정확하게 쓰지 못하거나 장면을 불필요하게 바꾸면 앱에 적용하지
않는다. 시안을 먼저 사용자에게 보여주고 승인받은 결과만 프로젝트 자산으로 복사한다.

## 앱 변경 범위

- `LaunchMotivationSplash`의 이미지 경로를 승인된 `v5`로 교체한다.
- 이미지 안의 문구와 같은 숨김 접근성 설명을 새 카피로 교체한다.
- 이미지 로드 후 1.5초 표시, 터치 종료, 세션 1회 노출, 원본 PNG 직접 로드 방식은
  그대로 유지한다.
- DB, 인증, Supabase, 서비스 워커, 다른 화면은 변경하지 않는다.

## 오류 처리

이미지 로딩 실패 시 보이는 검은 대체 화면도 같은 두 줄 문구를 사용한다. 이전 문구는
이미지 경로, 접근성 설명, 대체 화면 어디에도 남지 않아야 한다.

## 검증 기준

1. 생성 시안에서 두 줄 문구가 정확하며 오타·누락·추가 문자가 없다.
2. 상단 GND와 인물·배틀로프·빛·빗방울 구성이 기존 이미지와 일치한다.
3. 사용자 시안 승인 후에만 앱 자산과 코드에 반영한다.
4. 개발 서버의 새 세션에서 시작 이미지가 정확히 1개 나타난다.
5. 새 문구가 보이고 이전 문구는 보이지 않는다.
6. 이미지가 원본 크기로 직접 로드되며 약 1.5초 뒤 사라지고 터치 시 즉시 종료된다.
7. 관련 테스트, lint, typecheck, 전체 test, build가 통과한다.
8. 운영 배포는 별도 사용자 승인 후에만 진행하고 배포 뒤 운영 실물을 확인한다.

## 선택하지 않은 방식

- HTML 문구 오버레이: 한글 정확성은 높지만 기존 이미지 글자와 폰트 인상이 달라질 수
  있어 제외했다.
- 이미지 전체 재생성: 하단 문구 외의 장면과 인물이 바뀔 위험이 커서 제외했다.
