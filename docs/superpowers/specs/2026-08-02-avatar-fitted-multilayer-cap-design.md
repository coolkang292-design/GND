# GND 착용형 다중 레이어 모자 설계

작성일: 2026-08-02  
상태: 사용자 승인  
대상: 개발 목업 `/profile/avatar-mock`

## 1. 결론

현재 `gnd-cap-v2.png`처럼 상품 사진 한 장을 축소해 머리 위에 올리는 방식은 폐기한다. 기본 캐릭터 전체를 완성 사진으로 교체하지도 않는다. 모자 하나를 캐릭터의 머리와 귀에 맞춘 여러 개의 투명 레이어로 구성해 기존 1024×1536 좌표 합성 구조 안에서 장착한다.

## 2. 실패 원인

- 기존 모자는 캐릭터 머리용으로 제작된 이미지가 아니라 독립 상품 사진이다.
- 상품 사진의 원근과 캐릭터 머리의 원근이 다르다.
- 챙이 눈을 가리고, 귀와 모자의 앞뒤 관계가 없다.
- 이마 접촉 그림자가 없어 모자가 머리에서 떠 보인다.
- 단일 PNG의 위치와 크기만 바꿔서는 위 문제를 동시에 해결할 수 없다.

## 3. 합성 구조

기본 캐릭터는 그대로 유지하고 장착된 모자는 다음 순서로 합성한다.

| z | 레이어 | 역할 |
|---:|---|---|
| 30 | base | 기존 불독 캐릭터 |
| 40 | cap-crown | 머리 곡률을 따르는 모자 몸통 |
| 45 | ear-left-front / ear-right-front | 모자보다 앞으로 보여야 하는 귀 픽셀 복원 |
| 50 | cap-brim | 이마 앞쪽의 챙과 전면 로고 |
| 55 | cap-contact-shadow | 챙 아래와 관자놀이의 접촉 그림자 |

아이템마다 필요한 조각 수는 다를 수 있다. 런타임은 `layers[]` 배열만 순서대로 그리며 모자 전용 조건문을 만들지 않는다.

## 4. 에셋 제작 방식

1. `avatar-base-master.png`를 편집 대상으로 사용한다.
2. 사용자가 승인한 검은 `G` 캡 형태만 추가한 착용 기준 이미지를 만든다.
3. 얼굴, 몸, 자세, 복장, 조명, 캔버스 위치는 기준 이미지와 같아야 한다.
4. 착용 기준 이미지에서 모자 몸통, 귀 복원, 챙, 접촉 그림자를 분리한다.
5. 각 조각은 투명 PNG로 저장하고 실제 알파 경계로 잘라 좌표를 기록한다.
6. 밝은 배경과 어두운 배경에서 테두리, 들뜸, 색 번짐을 확인한다.

AI 편집 결과가 기본 캐릭터를 눈에 띄게 바꾸면 그 결과는 레이어 추출에 사용하지 않는다. 이 경우 GIMP에서 모자 부분만 보정하고 기본 캐릭터 픽셀은 원본을 사용한다.

## 5. 데이터 규격

매니페스트의 각 상품은 단일 좌표 객체가 아니라 `layers` 배열을 가진다.

```json
{
  "gnd-cap-v2": {
    "slot": "head",
    "layers": [
      {
        "id": "crown",
        "src": "/avatar-coordinate-v2/items/gnd-cap-v2/crown.png",
        "assetWidth": 360,
        "assetHeight": 220,
        "x": 320,
        "y": 110,
        "width": 360,
        "height": 220,
        "z": 40
      }
    ]
  }
}
```

실제 수치는 승인된 착용 기준 이미지에서 계산한다. 다른 5개 준비 중 상품도 동일한 `layers` 형식을 사용하되 기존 단일 PNG를 한 개짜리 배열로 감싼다.

## 6. 화면 동작

- 구매, 장착, 해제, 재장착 흐름은 바꾸지 않는다.
- 장착 시 해당 상품의 모든 레이어가 z순서대로 보인다.
- 레이어 하나가 로드되지 않으면 기본 캐릭터는 유지하고 오류 안내를 표시한다.
- 해제하면 모든 모자 레이어가 사라지고 기본 캐릭터가 정확히 복구된다.
- 다른 5개 상품은 계속 `준비 중`으로 비활성화한다.

## 7. 합격 기준

- 두 눈과 표정이 원본과 같고, 챙이 눈을 부자연스럽게 덮지 않는다.
- 모자 몸통이 머리 곡률과 카메라 각도를 따른다.
- 양쪽 귀와 모자의 앞뒤 관계가 자연스럽다.
- 이마와 챙 사이에 과하지 않은 접촉 그림자가 있다.
- 밝은 배경과 어두운 배경에서 녹색 테두리나 잘린 경계가 없다.
- 320px, 390px, 430px 너비에서 위치가 달라지지 않는다.
- 장착 해제 시 기본 캐릭터와 픽셀 구성이 동일하다.
- 개발 서버에서 구매 → 장착 → 해제 → 재장착을 직접 조작한다.

## 8. 범위 제한

- 이번 단계는 검은 `G` 캡 한 개의 품질 검증까지만 한다.
- Supabase, 실제 포인트 차감, 운영 배포는 포함하지 않는다.
- 모자가 승인되기 전에는 안경, 상의, 하의, 신발, 시계를 활성화하지 않는다.
- 모자 승인 후 슬롯별 가림 규칙을 별도 템플릿으로 확장한다.
