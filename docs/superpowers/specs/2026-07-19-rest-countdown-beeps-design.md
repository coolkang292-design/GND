# 휴식 종료 비프음 설계

## 목표

웨이트와 맨몸 운동의 세트 사이 휴식이 5초 남았을 때부터 이어폰으로 구분하기 쉬운 비프음을 재생한다. 유산소 운동에는 휴식 타이머와 비프음을 적용하지 않는다.

- 5초 남음: 짧은 `삠`
- 4초 남음: 짧은 `삠`
- 3초 남음: 짧은 `삠`
- 2초 남음: 짧은 `삠`
- 1초 남음: 긴 `삐임`
- 음성 안내와 추가 나레이션은 사용하지 않는다.

## 확인된 현재 상태

- 세트를 완료 처리하면 `draft.restSeconds` 값으로 휴식 타이머가 시작된다.
- 타이머는 `restRemaining`을 1초마다 줄이고 1초 이하에서 종료된다.
- 사용자는 휴식을 30초 늘리거나 즉시 건너뛸 수 있다.
- 운동 완료 또는 취소 시 휴식 타이머가 정리된다.
- 현재 3초, 2초, 1초 비프음과 관련 안전 처리가 구현돼 있다.
- 이번 변경은 짧은 비프음 시작 시점을 5초로 앞당긴다.

## 설계

### 1. 소리 생성

- 별도 음원 파일 없이 브라우저의 `Web Audio API`로 비프음을 만든다.
- 하나의 재사용 가능한 오디오 모듈이 소리 준비와 재생을 담당한다.
- 세트 완료 버튼을 누르는 사용자 동작에서 오디오를 미리 준비해 모바일 브라우저의 자동 재생 제한을 줄인다.
- 5초, 4초, 3초, 2초에는 같은 음높이의 짧은 소리를 약 120ms 재생한다.
- 1초에는 같은 음높이의 긴 소리를 약 350ms 재생한다.
- 이어폰 사용을 고려해 출력은 낮은 고정 음량으로 제한한다.

### 2. 타이머 연결

- 웨이트와 맨몸 운동의 세트 완료에만 휴식 타이머와 비프음을 적용한다.
- 유산소 세트 완료는 운동 기록만 갱신하고 새 휴식 타이머나 비프음을 시작하지 않는다.
- 웨이트·맨몸 휴식이 진행 중일 때 유산소 세트를 완료해도 기존 휴식은 유지한다.
- 운동이 진행 중이고 `restRemaining`이 5, 4, 3, 2, 1로 바뀔 때 각각 한 번만 재생한다.
- `+30초`로 시간을 늘린 뒤 다시 5, 4, 3, 2, 1에 도달하면 비프음을 다시 재생한다.
- 휴식 건너뛰기, 운동 완료, 운동 취소로 타이머가 사라지면 추가 소리를 재생하지 않는다.
- 기존 휴식 화면과 `휴식 끝` 안내 문구는 그대로 유지한다.
- 소리 켜기·끄기 설정, 음량 조절, 진동, 음성 나레이션은 추가하지 않는다.

### 3. 오류 처리

- 브라우저가 오디오 기능을 지원하지 않거나 재생을 차단하면 오류를 화면에 노출하지 않는다.
- 소리 재생 실패가 휴식 타이머, 세트 완료 처리, 운동 저장에 영향을 주지 않도록 분리한다.
- 화면이 잠기거나 브라우저가 완전히 백그라운드에 있으면 운영체제 정책 때문에 정확한 재생을 보장하지 않는다.

## 사용자 흐름

1. 사용자가 운동을 시작한다.
2. 웨이트 또는 맨몸 운동의 세트 완료 버튼을 누른다.
3. 설정된 휴식 시간이 시작된다. 유산소 운동이면 완료 기록만 반영하고 여기서 끝난다.
4. 5초 남음부터 2초 남음까지 매초 짧은 비프음이 난다.
5. 1초 남음에 긴 비프음이 난다.
6. 타이머가 종료되고 기존 종료 안내가 표시된다.

## 테스트

- 5초, 4초, 3초, 2초는 짧은 비프음 설정을 선택한다.
- 1초는 긴 비프음 설정을 선택한다.
- 6초 이상과 0초에는 비프음을 재생하지 않는다.
- 웨이트와 맨몸 운동은 휴식 타이머 대상이고 유산소는 대상이 아니다.
- 유산소 세트 완료가 진행 중인 웨이트·맨몸 휴식을 취소하지 않는다.
- 오디오 준비나 재생 실패가 호출부까지 오류를 전파하지 않는다.
- 휴식 건너뛰기와 운동 종료 후 추가 재생이 없다.
- 전체 테스트, 타입 검사, 코드 규칙 검사, 빌드를 실행한다.
- 로컬 모바일 화면에서 10초 휴식을 시작해 `삠`, `삠`, `삠`, `삠`, `삐임` 패턴을 직접 확인한다.
- 검증이 모두 통과하면 승인된 운영 배포를 실행하고 운영 주소의 응답을 확인한다.

## 제외 범위

- 음성 카운트다운
- 별도 음원 파일
- 사용자 설정 화면
- 음량 조절
- 진동
- 유산소 운동의 휴식 타이머와 비프음
- 화면 잠금 또는 백그라운드 재생 보장
- 푸시 알림과 네이티브 앱 기능
