## 2. 검수 결과 — 지킨 것과 고쳐야 할 것

### ✅ 지킨 것

- **비공개 권한**: 판정이 fail-closed다. `getSessionById`가 `select("*")`라 `visibility`를 실제로 읽고,
  `'group'`이 아니거나 세션을 못 읽으면 피드 버튼이 안 생긴다. 피드 쪽 코드는 손대지 않아
  딥링크 조회도 기존 `visibility='group'` 필터를 그대로 탄다(이중 방어)
- **XP·배지 지급**: `buildXpEvents`·서버 RPC 변경 없음. 화면에 보여주는 시점만 바뀌었다
- **인증사진 · 챌린지 · AI 코치** 순서·동작 변경 없음
- 주간 문구: 같은 날 2회는 1일로 센다, 월요일 경계(사용자 시간대), 이력 실패 시 숨김 —
  단위 테스트 5건이 있다. 비교는 **늘었을 때만** 말한다(손실 비교를 만들지 않는다)

## 4. 화면 확인

### 4-1. 픽스처 A 한 계정 — `pnpm dev` · `localhost:3000` · 375×812

| 조작 | 기대 결과 |
|---|---|
| 짧은 운동 1세트 완료 | 완료 화면이 **모달 없이** 바로 보인다. 화면 어디에도 `1 / N`이 없다 |
| 히어로 카드 첫 줄 | `이번 주 N일째…` 또는 `지난주보다 N일 더…` — **달력 탭의 이번 주·지난주 스탬프 수와 대조** |
| 보상 버튼 | XP 숫자 = 프로필 XP 증가분. 레벨업·배지가 있었으면 버튼 문구에 보인다 |
| 보상 버튼 탭 | 기존 보상 모달이 열리고 닫힌다. 닫은 뒤 완료 화면 그대로 |
| 피드 버튼 | `/feed?session=…`, **방금 운동이 맨 위에 고정** |
| 기록 탭으로 복귀 | 지난 완료 화면이 **남아 있지 않다** |
| 홈 버튼 | `/home`, 찌르기 버튼이 열려 있다 |
| 공유 버튼 | OS 공유/복사 토스트. **`운동 일지 공유하기` 문구가 없다** |
| (Q2 유지 시) 홈 경고 배너 | d1·d2 문구가 375px에서 카드 레이아웃을 밀지 않는다 — 스트릭 상태는 날짜를 조작할 수 없으니 **문구 단위 테스트 + 가장 긴 문구를 임시로 강제 렌더**해서 본다 |
