# Web Push Notifications Implementation Plan

> **보관됨 — 실행이 끝난 계획서다.** 여기 적힌 단계를 실행하지 마라.
> 체크박스가 비어 있어도 미완료가 아니다 — 실행하면서 표시하지 않았을 뿐이다.
> 현행 사실은 **코드**와 `docs/db-current-schema.sql`이다. 왜 보관하는지는 `../README.md`.

**Goal:** 알림함에 저장되는 모든 알림을 잠금화면 웹 푸시로도 발송한다 (spec: `docs/superpowers/specs/2026-07-19-web-push-design.md`).

**Architecture:** notifications INSERT → pg_net 트리거 → `/api/push/notify`(service_role 재조회·중복 방지) → web-push(VAPID) → 서비스워커 표시. 클라이언트는 프로필 토글로 구독을 `push_subscriptions`에 저장.

**Tech Stack:** Next.js 16 App Router, Supabase(pg_net trigger, RLS), web-push, Service Worker Push API
