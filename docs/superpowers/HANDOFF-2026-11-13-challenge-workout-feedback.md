## 사용자 승인 범위와 결과

- 운동 후: 서버에 저장·집계된 이번 세션을 제외/포함한 두 결과로 기본 점수 증가량·전후 점수·전후 종합 순위를 표시. 상대 기록은 조회 시점 고정이며 실제 과거 순위 이력을 복원한다고 말하지 않는다.
- 운동 전: 오늘 일반 계획을 모두 수행했을 때 예상 기본 점수, 계획보다 추가로 얻는 점수가 있는 운동 1~2개 제안. 기존 계획/최근 익숙한 종목만 사용하고 무게를 올리지 않는다. 시간/거리/반복 추가량 상한이 있으며 사용자가 버튼을 눌러야 계획에 반영된다.
- active+joined만 대상. 미참가·초대·종료·탈퇴는 기존 화면 유지. 공개하지 않은 방은 기존 누적 실적 카드 유지, 예상/실제 점수·순위·점수 제안은 비노출.
- 사진 필수 방은 인증 전 대기. 서버 조회에 이번 session_id가 없으면 0점 또는 성공이라고 단정하지 않고 재확인을 제공한다. 운동 저장·XP 지급은 추가 조회와 분리.
- 완료 카드 링크는 `?open=<id>&ranking=overall`로 같은 종합점수 순위에 바로 연결. 비공개/미참가 방은 이 주소로도 종합 순위 진입 불가.
