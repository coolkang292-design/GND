## 1. 기록 화면 — 빈 상태

- [ ] 1.1 주 버튼이 **`운동 계획하기`** (옛 `＋ 첫 운동 추가하기`)
- [ ] 1.2 저장된 루틴이 있으면 **`내 루틴에서 추가하기`** 가 보인다
- [ ] 1.3 루틴이 없는 계정에서는 그 버튼이 **안 보인다**

## 2. 운동 추가 허브

- [ ] 2.1 카드 **4개**만 — 프로그램 / 직접 고르기 / 지난 운동 / 내 루틴
- [ ] 2.2 위 두 장이 **같은 크기 사진 카드**, 프로그램 쪽만 금색 테두리
- [ ] 2.3 인터벌 진입 카드가 **없다** (프로그램 안으로 들어갔다)

## 3. 프로그램 목록·상세

- [ ] 3.1 카드 **6장** — 마지막이 `짧고 굵게 태우는 전신`
- [ ] 3.2 목록 상단 **`← 운동 추가로`** 로 빠져나간다
- [ ] 3.3 새 문구 — 가슴 `티셔츠 핏을 살리는 가슴` · 팔 `반팔이 달라지는 팔` ·
      하체 `몸의 기반을 만드는 하체` · 감량 `살은 빼고, 몸은 선명하게`
- [ ] 3.4 하체·감량 카드 **이미지가 새것**인지 (`bb81fe8`)
- [ ] 3.5 카드 하단이 `총 18회 · 회당 …분` (옛 `주 3회 · 6주 …`)
- [ ] 3.6 인터벌 상세 — 난이도 탭 **입문/보통/높음**, 탭마다 A·B·C 종목이 **바뀐다**
- [ ] 3.7 주차별 길이 — 입문 4·4·8·8·8·8 / 보통 4·4·8·8·16·16 / 높음 8·8·16·16·16·16
- [ ] 3.8 **종목 이름을 누르면** 시작 자세·동작·호흡·흔한 실수·주의가 펼쳐진다
- [ ] 3.9 높음의 **버피**(A·C 두 곳)를 눌렀을 때 **하나만** 펼쳐진다

## 4. 프로그램 등록

- [ ] 4.1 요일을 **2~5개** 고를 수 있다 (옛 3개 고정)
- [ ] 4.2 요일 **2개**로 등록 → 18회가 약 9주에 담긴다
- [ ] 4.3 요일 **5개**로 등록 → 18회가 약 4주에 담긴다
- [ ] 4.4 인터벌 등록 2단계의 난이도 칸이 **3개** (근력은 2개)
- [ ] 4.5 등록 완료 → `달력에서 계획 확인하기` → **달력 탭**으로 착지
- [ ] 4.6 이미 등록한 프로그램을 열면 `진행 중인 프로그램 보기`
- [ ] 4.7 그 링크도 **달력 탭**으로 착지

## 5. 달력

- [ ] 5.1 오늘 계획 버튼이 **`운동 시작하기`** — `준비하기` 단계가 없다
- [ ] 5.2 오늘 인터벌 계획은 **`🔥 전신 인터벌 시작하기`** → 바로 전체화면
- [ ] 5.3 근력 계획 카드가 `0kg 0회`가 아니라 **`8–10회 목표`** +
      `무게는 시작할 때 최근 기록으로 채워져요`
- [ ] 5.4 인터벌 계획 카드는 종목마다 **`2회`** (입문 1주차 4분)
- [ ] 5.5 프로그램 계획 카드에 **`이 회차만 삭제`** 와 **`프로그램 그만두기`**
- [ ] 5.6 `프로그램 그만두기` → 남은 회차 수를 묻고 확인하면 **한 번에 사라진다**
- [ ] 5.7 그만둔 뒤 같은 프로그램을 **다시 등록**할 수 있다
- [ ] 5.8 일반 계획에는 `삭제` 하나뿐 (그만두기 없음)
- [ ] 5.9 지난 **인터벌** 기록 → 📋 복사 → **복사된다**
      (예전엔 `복사할 종목이 없어요`로 막혔다)
- [ ] 5.10 이미 운동이 있는 날은 프로그램이 **건너뛰고** 가까운 빈 날로 배치
      (의도된 동작 · 사용자 확정)

## 6. 인터벌 실행 ⭐ 가장 중요

- [ ] 6.1 **전체화면 하나만.** 뒤에 ± 버튼·`현재 세트`가 안 보인다
- [ ] 6.2 구성 — 지금 종목(크게) · `다음: ○○` · 응원 문구 · 종목 4칩 · 진행률 막대
- [ ] 6.3 카운트다운 **숫자가 없다** (숫자는 음악이 센다)
- [ ] 6.4 **소리와 화면** — 음악이 "3·2·1" 하고 종목을 부를 때 화면도 같이 바뀐다
- [ ] 6.5 **8분 후반부**(4분 이후)도 여전히 맞는다 (음원을 다시 이어 붙인 이유)
- [ ] 6.6 20초 뒤 자동으로 다음 종목 · 10초 휴식
- [ ] 6.7 응원 문구가 구간에 맞고 **깜빡이지 않는다**
      (운동엔 미는 말, 휴식엔 회복하는 말)
- [ ] 6.8 마지막 라운드에 `마지막 라운드! 끝까지`
- [ ] 6.9 진행률 막대가 **보이고** 라운드마다 찬다
- [ ] 6.10 일시정지 → 이어서 — 음악과 함께 멈췄다 재개
- [ ] 6.11 4분 끝까지 → **자동 종료 + 자동 기록**

> ⚠️ 6.4가 어긋나면 **몇 초 차이인지**만 알려주면 상수 하나로 맞춘다
> (`INTERVAL_PREP_SECONDS`, 현재 13초).

## 확인 뒤 배포 순서

1. 위 항목 확인 (이상 있으면 여기서 멈추고 고친다)
2. `pnpm lint && pnpm typecheck && pnpm test && pnpm build`
3. `main` 반영
4. **사용자 배포 승인**
5. `git archive HEAD`로 푼 `.git` 없는 폴더에서 `vercel --prod`
6. 프로덕션에서 **파일을 직접 받아** 새 코드가 들어갔는지 확인
7. 릴리스 노트 항목 추가 + **DRY RUN까지만** (발송은 별도 지시)

## 배포를 막지 않는 미완 3건

- **인터벌 9조합이 검수되지 않았다** — 설계 §3.3이 스스로 그렇게 적고 있다.
  완화책인 등록 전 회차 편집(§3.5)도 아직 없다. **가장 큰 미검증 항목**이다
- **네이버 지식백과 링크** — 화면 자리는 만들었으나 URL이 하나도 없다.
  이 세션에 웹 접근이 없어 열어 확인할 수 없었고, 규칙상 추측해 넣지 않는다
- **분할(스플릿) 프로그램** — 주 4~5회에서 성립한다. `PROGRESS.md`에 계획으로 남겼다
