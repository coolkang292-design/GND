# GND 마케팅 소재 원칙

> 사용자 지시 (2026-10-07). 카드뉴스·썸네일·영상·광고 등 GND 마케팅 소재 전부에 적용한다.
> 이 문서가 단일 원천이다. 도구별 README(예: `tools/demo-video/README.md`)는 이 문서를 따른다.
>
> 이전 원칙("실제 GND 화면만 쓴다. 가짜 UI·목업·AI 생성 장면·과한 전환 효과는 쓰지 않는다")은 이 문서로 **대체됐다.**

## 1. AI는 최대한 활용한다

카드뉴스, 썸네일, 영상의 비주얼, 배경, 캐릭터, 연출 장면, 카피와 훅, 컨셉 화면 모두 AI로 만들 수 있다.

## 2. 사실은 사실대로

- **수치**(운동 횟수, 성과, 파일럿 결과), **기능 설명**, **후기와 사례**는 실제 데이터와 화면에 근거한다.
- **앱에 없는 기능을 보여주지 않는다.**
- 예외: 앱의 기능을 설명하기 위해 **수치를 임의로 만들어** 제작할 수 있다. 이때는 반드시 **"컨셉"으로 표기**한다.

| 구분 | 근거 | 표기 |
|---|---|---|
| 성과·파일럿 결과·사용자 수 등 "실제로 이랬다"는 주장 | 실제 데이터 (테스트 계정 제외) | 없음 |
| 후기·사례 | 실제 사용자 | 없음 |
| 기능 설명용 예시 수치 (예: 볼륨 1,200kg, 챌린지 58%) | 임의 생성 가능 | **"컨셉"** |
| AI로 만든 앱 화면 | 앱에 실제로 있는 기능만 | **"컨셉"** |
| AI로 만든 연출 장면·인물·배경 | — | 필요하면 **"연출"** |

## 3. AI 표기

- AI로 만든 앱 화면과 연출은 필요한 경우 **"컨셉"** 이나 **"연출"** 로 표기한다.
- 각 플랫폼(인스타그램·유튜브·틱톡 등)의 **AI 콘텐츠 표시 규정**을 따른다.

## 4. 비용과 외형

- **저비용 시안으로 먼저 테스트**하고, 승인 후 고화질로 만든다.
- **자연스러운 외형** 기준은 유지한다.
