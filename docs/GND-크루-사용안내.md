## 2️⃣ 시작하기 (⚠️ 반드시 이 순서대로! — 설치 먼저, 가입은 그다음)

### ① 링크를 사파리/크롬으로 열기 (가입은 아직 하지 마세요)
카톡으로 받은 링크를 눌러서 여세요.
- 아이폰: 카톡에서 열리면 오른쪽 아래 **사파리 아이콘**을 눌러 사파리로 열기
- 안드로이드: 크롬으로 열기

### ② 홈 화면에 설치하기 (프로필 만들기 전에!)

**아이폰 (사파리)**
1. **공유 버튼** (⬆️ 네모에 화살표) 누르기
2. 아래로 내려서 **"홈 화면에 추가"** → **추가**

**안드로이드 (크롬)**
1. 오른쪽 위 **점 3개(⋮)** 메뉴 → **"홈 화면에 추가"** (또는 "앱 설치")

### ③ 홈 화면 GND 아이콘으로 열어서 가입하기 (30초)
1. 프로필 이모지 → 닉네임 → 주간 목표 입력
2. **"초대 코드로 참여하기"**를 눌러 카톡으로 받은 **초대 코드**(GND-XXXXX) 입력 → 크루 합류!

> ❗ 가입은 **홈 화면 앱에서 딱 한 번만** 하세요. 같은 닉네임으로는 두 번 가입할 수 없게 막아뒀어요 — "이미 사용 중인 닉네임" 안내가 뜨면 이미 가입된 거니까, 원래 가입했던 기기·브라우저에서 쓰세요.

### ④ 잠금화면 알림 켜기 🔔
홈 화면에 **"🔔 잠금화면 알림 켜기"** 카드가 보이면 **켜기 → 허용**을 눌러주세요.
앱이 꺼져 있어도 응원·찌르기·아침 브리핑이 잠금화면으로 옵니다!
(카드를 놓쳤으면 **내 정보 탭 → 기기 푸시 알림 → 켜기**. 아이폰은 홈 화면에 설치한 앱에서만 푸시가 돼요.)

## 3️⃣ 사용법 — 이것만 알면 됩니다

### 🏋️ 운동 기록하기 (핵심!)
1. 아래 탭에서 **기록** 누르기
2. **운동 추가** → 종목 검색해서 선택 (여러 개 한번에 가능, 없으면 직접 만들기)
3. 세트마다 무게·횟수 입력하고 **완료(✔) 체크**
4. 체크하면 **휴식 타이머**가 자동 시작 — 끝나기 5초 전부터 `삠·삠·삠·삠·삐임` 소리가 나요
5. 다 했으면 **운동 완료** → **인증 사진 촬영** 📸 (챌린지 인정받으려면 필수!)

### 🔔 소리가 안 들린다면
- **아이폰은 무음(진동) 모드면 비프음이 안 납니다** → 운동할 때는 옆면 스위치를 **벨소리 모드**로!
- 음악 들으면서 운동해도 비프음이 같이 들려요 🎵

### 📅 달력
기록 탭 → 달력에서 운동한 날 스탬프 확인. 지난 운동을 **복사**해서 다음 운동 예정일에 넣어둘 수도 있어요.

### 🏆 챌린지
챌린지 탭에서 크루 챌린지 만들기·참여. 기간 동안 **사진 인증한 운동만** 인정!
꾸준히 하면 불독 레벨이 올라가요 (Lv.1 잠만보 불독 → Lv.5 개노답 탈출 🐶)

### 💬 피드
크루원 운동 인증에 🔥👏❤️ 반응 남기기, 운동 중인 친구에게 실시간 **응원** 보내기, 오늘 운동 안 한 친구 **콕 찌르기** 👉

### 🌅 아침 브리핑
매일 아침 9시쯤 알림함에 오늘의 브리핑이 도착해요.
